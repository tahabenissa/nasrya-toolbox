## Зачем Winsploit?

Kali — дом инструментов безопасности, но многие работают в **Windows**, а существующие варианты
заставляют идти на компромисс:

| Вариант | Плюсы | Чего не хватает |
|---|---|---|
| **Commando VM / FLARE-VM** | Отличные, полные | Одноразовые *провиженеры ВМ*, а не ежедневный запускатель |
| **PentestBox** | Верная идея: нативно и портативно | Заброшен с ~2016, неясная лицензия |
| **UniGetUI** | Отличный GUI для пакетов | Нет отбора по безопасности и сценария «запустить инструмент» |
| **Winsploit** | Отобрано, нативно, ставит **и** запускает, MIT, активно развивается | Alpha |

Нет поддерживаемого нативного запускателя для Windows с ясной лицензией, который бы одновременно
*устанавливал* и *запускал* инструменты безопасности из единого интерфейса. Winsploit закрывает этот
пробел и честно говорит, что реально работает в Windows, а что требует Linux.

## Быстрый старт

**Проще всего (без админа):** скачайте `winsploit-<версия>-setup.exe` со страницы
[Releases](https://github.com/tahabenissa/winsploit/releases). Установщик добавит его в PATH, может
настроить Scoop, git, bucket'ы и pipx и даёт отметить наборы инструментов. Откройте **новый** терминал
и введите `winsploit`. Бинарник не подписан (SmartScreen: «Подробнее» → «Выполнить в любом случае»);
проверьте его по `SHA256SUMS`.

**Или собрать из исходников:**

**Нужно:** Windows 10/11, [Scoop](https://scoop.sh) и [Rust 1.87+](https://rustup.rs).

```powershell
# 1. Установить Scoop (пропустите, если уже есть)
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression

# 2. Собрать winsploit
git clone https://github.com/tahabenissa/winsploit
cd winsploit
cargo build --release

# 3. Сделать `winsploit` командой (добавляет target\release в PATH, без админа)
.\target\release\winsploit setup --path --shortcut

# 4. Открыть новый терминал, перейти в рабочую папку и запустить
cd C:\ctf\some-box
winsploit
```

Выберите инструмент с `↑/↓` (или `/` для фильтра), нажмите `i`, чтобы установить, и `Enter`, чтобы
запустить. В любой момент нажмите `?`, чтобы увидеть все клавиши.

## Возможности

### Панель, созданная для клавиатуры
- **Просмотр по категориям** с живым статусом установки: `●` установлен, `○` отсутствует, `◐` конфликт.
- **Мгновенный фильтр (`/`)** по имени, категории или описанию.
- **Настоящий строчный редактор** аргументов, с **историей** по каждому инструменту (`↑/↓`).
- **Справка по клавишам (`?`)**.

### Живой, интерактивный вывод
- stdout/stderr **транслируются в панель вывода** в реальном времени, с цветом.
- **Общайтесь с запущенными инструментами.** У каждого процесса свой канал ввода (`Ctrl+D` = конец ввода).
- **Прокрутка** (`PgUp/PgDn/Home/End`) и **поиск в выводе** (`f`, `n`, `N`).
- **`c` отменяет** всё дерево процессов, а не только родителя.

### Установка в одно нажатие, по-человечески
- **Scoop** для нативных инструментов, с **автодобавлением нужных bucket'ов** при первом использовании.
- **pipx** для Python-инструментов (каждый в своём venv; Python и pipx ставятся при необходимости).
- **Собственный Scoop-bucket Winsploit** для того, что никто не пакует, с **проверкой SHA-256**.
- Обнаружение идёт **вне UI-потока** — панель никогда не зависает.

### Сделано для CTF
- **Рабочие пространства задач (`C`)**: папка на каждую задачу с целью, форматом флага, файлами, заметками, логами и флагами.
- **Рецепты**: `Enter` на nmap, ffuf, john… предлагает готовые команды с подставленными `{target}`, `{file}`, `{out}`, `{wordlist}`.
- **Ловец флагов**: `picoCTF{…}`, `HTB{…}`, `flag{…}` подсвечиваются, объявляются, копируются и сохраняются.

### ИИ-агент в контуре
- Нажмите **`a`**: ИИ читает вывод текущего терминала и предлагает следующие шаги в виде **команд
  инструментов из каталога, которые вы подтверждаете перед запуском**. Сам агент никогда не запускает shell.
- **`A`** выбирает провайдера: **Claude CLI** (использует вашу сессию, без ключа), либо
  **Gemini / DeepSeek / OpenAI**, либо локальную модель **Ollama** — с настраиваемой моделью для каждого
  провайдера. Ключи читаются из окружения.

### Та же сессия в браузере
Терминал остаётся главным приложением, а браузер — второе окно в **ту же живую сессию**. `w`
запускает/останавливает веб-вид, `o` открывает его. **`--lan`** (или `W`) отдаёт его в локальную сеть
**по HTTPS**, с одноразовым ключом доступа и вашим одобрением каждого гостя.

### Управляется конфигом, честен по устройству
- Каждый инструмент — **запись в YAML**, так что добавить новый можно без кода.
- **Обнаружение самозванцев**: `verify:` ловит одноимённые программы и отказывается запускать не ту.

## Использование

```text
winsploit                 запустить интерактивную панель
winsploit list            вывести каталог со статусом установки
winsploit hashid <h>…     определить один или несколько хешей (подсказки hashcat -m / john --format)
winsploit --help, -h      показать справку
winsploit --version, -V   показать версию
```

### Клавиши панели

| Клавиша | Действие |
|---|---|
| `↑` `↓` | Двигать выбор |
| `/` | Фильтр по имени, категории или описанию |
| `Enter` | Запустить выбранный инструмент (отредактируйте аргументы, затем `Enter`) |
| `i` | Установить инструмент (Scoop или pipx) |
| `r` | Повторно определить установленное |
| `f` · `n` · `N` | Поиск в выводе · предыдущее · следующее совпадение |
| `c` | Отменить текущий процесс (всё дерево) |
| `h` | Определить хеш (встроенно, офлайн) |
| `a` · `A` | ИИ-агент: прочитать вывод и предложить шаги · выбрать провайдера / модель |
| `p` | Проекты: создать / открыть рабочую папку, с недавними |
| `d` | Рабочая папка: где работают инструменты, как `cd` |
| `C` | Задачи: создать, переключить, задать цель / формат флага |
| `F` | Пойманные в выводе флаги |
| `S` | Запустить инструмент в Windows Sandbox |
| `t` | Оформление: тема, рамки, глифы (живой предпросмотр) |
| `w` · `W` · `o` | Веб-вид: старт / отдать в LAN / открыть |
| `?` | Показать все клавиши |
| `q` | Выход |

## Участие

Добавить инструмент проще всего: добавьте запись в [`tools.yaml`](tools.yaml) (и манифест в `bucket/`,
если его никто не пакует), запустите `cargo test` и откройте PR. Добавляйте только инструменты, реально
работающие нативно в Windows, и документируйте оговорки через `note:`.
