The catalog is one YAML file with two top-level keys: `buckets` and `tools`. When it loads, **every problem is reported at once** (a missing `scoop:`, a web tool without `url:`…), not just the first.

## A complete entry

```yaml
tools:
  - name: gobuster
    categories: [recon, web]
    description: Directory / DNS / vhost brute-forcing
    exe: gobuster
    scoop: gobuster
    run_cmd: gobuster
    args_hint: 'dir -u https://example.com -w "{app:seclists-lite}\common.txt"'
    options:
      - { flag: dir, help: 'brute-force paths on a web server' }
      - { flag: '-u', arg: '<url>', help: 'the target URL' }
      - { flag: '-w', arg: '<wordlist>', help: 'the wordlist to try' }
```

## Fields

| Field | Required | Meaning |
|---|---|---|
| `name` | yes | Display name |
| `categories` | yes | Every category the tool is useful in, **primary first**: `[web, recon]`. Known ids, in dashboard order: `osint recon network web exploit passwords reversing pwn mobile forensics crypto stego wordlists`. Others work too and are listed last. `category: web` is still accepted for a single one |
| `description` | yes | One line, shown in the output pane header |
| `exe` | yes | The executable used to **detect** the install, looked up on `PATH` (`.exe` `.com` `.bat` `.cmd`). May be any file that proves the install, e.g. `'{scoop_app}\dnSpy.exe'` |
| `install` | no | `scoop` (default) or `pipx` |
| `scoop` | with Scoop | Scoop package name |
| `bucket` | no | Scoop bucket the package lives in; main-bucket tools omit it. Added automatically before installing |
| `pipx` | with pipx | pipx spec: `arjun`, `pkg==1.2` or `git+https://github.com/o/r`. Python and pipx are bootstrapped through Scoop if needed |
| `run_cmd` | usually | The command actually launched. May be empty for a URL-only web tool |
| `args_hint` | no | Arguments prefilled when you press Enter (you edit them before running) |
| `launch` | no | `stream` (default), `gui`, `web` or `dataset`. See [launch modes](/docs/catalog/launch-modes) |
| `url` | with `web` | The http(s) URL (or local page) opened by `launch: web` |
| `note` | no | Caveat shown every time the tool runs. See [verify & notes](/docs/catalog/verify-and-notes) |
| `verify` | no | `{ args: "-version", contains: "text" }`: impostor check at detection time |
| `recipes` | no | Named argument presets offered on `Enter`: `[{ name: quick, args: '-sV -T4 {target}' }]`. Placeholders `{target}` `{file}` `{out}` `{wordlist}`, written unquoted. See [recipes](/docs/using/recipes) |
| `secret_args` | no | Flags whose value is a secret, masked in the pane's `$` line and the run log: `[-p, --password, "-H Authorization"]`. Not allowed on `dataset` tools. See the [security model](/docs/security/model#secrets-stay-out-of-the-pane-and-the-logs) |
| `options` | no | Flags and subcommands the web view's [command helper](/docs/web-view/overview#the-command-helper) suggests and explains: `[{ flag: -p, arg: '<ports>', help: ports to scan }]`. `flag` is one word (a subcommand like `dir` works too), `arg` only for flags that take a value, `help` one line. Quote values that start with `-` or `<`. A flag listed twice or one without `help` is reported as an error |
| `sandbox` | no | `never` (default), `optional` or `recommended`: `S` runs the tool in [Windows Sandbox](/docs/using/sandbox). Scoop `gui` / `stream` tools only; use `recommended` for tools that execute the sample |
| `sandbox_deps` | no | Scoop packages mapped read-only into the sandbox and put on `PATH`, e.g. `[temurin25-jdk]` |

## buckets

Maps a bucket name to its git URL. Only needed for buckets Scoop doesn't know by name; `extras`, `versions`, `java`… need no entry.

```yaml
buckets:
  security: https://github.com/opsqw/scoop-security
  winsploit: https://github.com/tahabenissa/winsploit
```

## Placeholders

`{scoop_app}` and `{app:NAME}` expand to Scoop app folders. See [Placeholders](/docs/catalog/placeholders).

::callout{type="important" title="Quote Windows paths with single quotes"}
Inside `"double quotes"`, YAML turns `\r`, `\x`, `\c`… into escape sequences. Write Windows paths in `'single quotes'`.
::
