Some useful tools have no Windows package anywhere. Winsploit's repository doubles as a **Scoop bucket** for them: gau, John the Ripper (jumbo), steghide, nikto and SecLists-lite.

```powershell
scoop bucket add winsploit https://github.com/tahabenissa/winsploit
```

You don't need to add it yourself: pressing `i` on one of these tools adds it first.

## Why it's safe to use

Each manifest in [`bucket/`](https://github.com/tahabenissa/winsploit/tree/main/bucket) has a **pinned download URL and SHA-256 hash**. Scoop handles the download, verifies the hash, extracts and creates shims; a file that doesn't match is refused.

## Adding a manifest

1. Add `bucket/<name>.json` with a fixed `url` and its `hash`.
2. Set `bucket: winsploit` on the tool's catalog entry.
3. Run `cargo test`. `bucket_tests.rs` checks that every manifest is well-formed and that every `bucket: winsploit` entry has one.
