Press **`T`** to open a chat panel beside the terminals. Say what you want, for example *"scan 10.0.0.5 for open ports"*. The AI answers with a short reply and, at most, **one catalog tool with its arguments**. That plan waits for you: **`Enter` runs it**, `Esc` skips it.

It already knows what it needs, so you don't have to explain your setup:

- the catalog, and which tools are installed
- your working folder
- the active [challenge](/docs/using/challenges)'s target
- the terminal in front, so *"what did it find?"* reads that output

## How a run happens

The chat never runs anything itself. A plan is parsed into a real argument list and goes through the normal launcher, exactly like a run you typed. It lands in a terminal beside the chat, the install, [conflict](/docs/catalog/verify-and-notes) and quoting checks all still apply, and the chat tells you when the run ends.

## Keys

| Key | Action |
|---|---|
| `T` | Open the chat and type |
| `Enter` | Send your message · run the shown plan |
| `Esc` | Skip the plan · give the keys back to the dashboard |
| `Ctrl+T` | Show or hide the panel |
| `PgUp` · `PgDn` | Scroll the transcript |
| `/clear` | Start the conversation over |

## Running plans without asking

Plans wait for `Enter` by default. Set `chat-autorun: true` in [settings.yaml](/docs/reference/settings) to run them straight away. It is off by default because tool output is text from the target, and a hostile target could try to steer the AI.

## Provider

The chat uses the provider you picked with `A` (see [AI agent](/docs/using/agent#providers)). With the Claude CLI it is called in an isolated mode: no tools, no MCP servers, no hooks, no slash commands, no saved session, its own system prompt and a scratch folder. It would otherwise inherit your own Claude Code permissions while reading untrusted output, and a CLI too old to support this is refused instead of used anyway.

::callout{type="warning" title="Output leaves your machine"}
Your messages, the catalog summary and the tail of the shown terminal go to the provider you picked. Secrets are masked first (see the `redact` setting), but choose Ollama if the data must stay local.
::

## Terminal only

The chat is not available in the [web view](/docs/web-view/overview): no web action can open it or send to it, like [Sandbox](/docs/using/sandbox) runs.
