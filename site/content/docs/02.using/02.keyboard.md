Press `?` in the dashboard to see this list any time.

## Browsing

| Key | Action |
|---|---|
| `↑` `↓` · `j` `k` | Move in the tool list |
| `←` `→` · `[` `]` | Switch category: All · Installed · OSINT … Wordlists |
| `/` | Filter tools by name, category or description (`Esc` clears) |
| `r` | Re-detect installed tools (picks up `PATH` changes) |

## Running

| Key | Action |
|---|---|
| `Enter` | Run the tool in a free terminal (edit the arguments first) · dataset: list its files |
| `i` | Install the selected tool (Scoop or pipx), in the console |
| `s` | Send a line to the shown tool's input |
| `Ctrl+D` | End of input (EOF) for the shown tool |
| `c` | Stop the shown tool and its whole process tree (its output stays) |
| `x` | Close the shown terminal (press twice if its tool is running) |

## Terminals and output

| Key | Action |
|---|---|
| `0`–`4` · `Tab` | Show the console (0) or terminal 1–4 · `Tab` cycles |
| `g` | Grid: all four terminals at once |
| `PgUp` `PgDn` | Scroll · `Home` top · `End` follow live output |
| `f` · `n` · `N` | Find in output · older match · newer match |

## Tools and settings

| Key | Action |
|---|---|
| `h` | Identify a hash (built in, offline) |
| `d` | [Working folder](/docs/using/running-tools#the-working-folder): where tools run, like `cd` · `Tab` completes · `..` `~` `-` work |
| `S` | Run the selected tool in [Windows Sandbox](/docs/using/sandbox) · `Tab` in the prompt = network on/off |
| `C` | [Challenge workspaces](/docs/using/challenges): pick, create or edit the active challenge |
| `F` | List the [CTF flags](/docs/using/flags) caught in the output |
| `a` · `A` | [AI agent](/docs/using/agent): analyse the shown output · pick provider and model |
| `T` · `Ctrl+T` | [Side chat](/docs/using/chat): say what you want, the AI picks the tool and asks before running it · show / hide the panel |
| `t` | Appearance: theme, borders, glyphs, overlays |
| `w` · `W` | Web view: start / stop it · serve your LAN |
| `o` | Open the web view in your browser |
| `L` | LAN guests: join key · let in (`v` watch, `f` full control) · `x` remove · `n` new key |
| `?` | Show every key |
| `q` · `Esc` | Quit (press twice if tools are still running) |

## In prompts

The arguments prompt and the hash prompt are real line editors:

| Keys | Action |
|---|---|
| `←` `→` · `Ctrl+←` `Ctrl+→` | Move by character · by word |
| `Home` `End` · `Ctrl+A` `Ctrl+E` | Start / end of line |
| `Del` · `Ctrl+Backspace` / `Ctrl+W` · `Ctrl+U` | Delete char · delete word · clear to start |
| `↑` `↓` | Cycle through arguments you've used with this tool |
| Paste | Whole command lines work |

## In the web view

| Key | Action |
|---|---|
| `/` | Filter tools |
| `↑` `↓` · `j` `k` | Move in the tool list |
| `←` `→` | Switch category |
| `Enter` | Edit the arguments, then run |
| `Ctrl+Space` · `Tab` | In the arguments: open the suggestions (flags, recipes, history, challenge files) · insert one |
| `b` | Show or hide the tool list |
| `p` | Colors: pick a palette, light or dark |
| `,` | Settings |
| `0`–`4` | Show the console or terminal 1–4 |
| `g` | Grid of all four terminals |
| `f` | Find in the shown terminal (`Enter` older, `Shift+Enter` newer) |
| `Ctrl+D` | In a tool's input: end of input |
| `Esc` | Leave a field or close a dialog |
| `?` | Shortcut list |
