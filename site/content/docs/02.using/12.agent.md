Press **`a`** and an AI reads the shown terminal's recent output, then answers with a short **summary**, the **findings** worth noting and **suggested next steps**. Each suggestion names a catalog tool and its arguments.

Prefer to just say what you want? The [side chat](/docs/using/chat) (`T`) turns plain language into a catalog-tool run.

The AI is the brain only. It gets **no tool execution**: picking a suggestion puts that tool and its arguments into the normal args prompt, where you review them and press `Enter` yourself. Every run still goes through the usual install, [conflict](/docs/catalog/verify-and-notes) and argument checks, so the agent can never run an arbitrary shell command.

## Keys

| Key | Action |
|---|---|
| `a` | Analyse the shown terminal's output (and close the result) |
| `↑` `↓` · `j` `k` | Move between suggestions |
| `Enter` | Take the suggestion into the args prompt (review, then `Enter` runs it) |
| `Esc` · `q` | Close |
| `A` | Pick the provider and model |

## Providers

Press **`A`** to pick one. The picker shows whether each is ready or what it still needs.

| Provider | Needs | Default model |
|---|---|---|
| Claude | the `claude` CLI on `PATH` (reuses your Claude Code login, no API key) | `sonnet` |
| Gemini | `GEMINI_API_KEY` | `gemini-2.0-flash` |
| DeepSeek | `DEEPSEEK_API_KEY` | `deepseek-chat` |
| OpenAI | `OPENAI_API_KEY` | `gpt-4o-mini` |
| Ollama | a local server on `http://localhost:11434` | `llama3.1` |

The HTTP providers are called through `curl`, which ships with Windows 10 and 11. Set an API key as a user environment variable, then restart Winsploit.

In the picker, `m` edits the highlighted provider's model and `r` resets it to the default. `Enter` selects the provider. Both choices are saved to [settings.yaml](/docs/reference/settings).

::callout{type="warning" title="Output leaves your machine"}
The last 150 lines of output (up to 6,000 characters) and the command you ran are sent to the provider you picked. With Claude, Gemini, DeepSeek or OpenAI that's a third-party service, so don't analyse output from engagements whose data must stay local. Ollama keeps everything on your machine.
::
