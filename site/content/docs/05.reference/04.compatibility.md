Winsploit is honest about what really works on Windows.

| Works great | Works, with notes | Use Linux instead |
|---|---|---|
| nmap, nuclei, ffuf, gobuster, httpx, subfinder, katana, radare2, Ghidra | **hashcat** needs GPU drivers · **tshark** needs Npcap and admin · Python tools need pipx (Winsploit bootstraps it) | **Live Wi-Fi capture** (aircrack-ng: no monitor mode or injection) · THC-Hydra, WPScan, WhatWeb, masscan (degraded on Windows) |

## Wireless, honestly

Live Wi-Fi monitor mode and packet injection **don't work** on Windows with normal adapters. Only *offline* cracking of captures you already have is useful here. For real wireless work, use Linux with a supported USB adapter. That's why aircrack-ng is deliberately left out of the catalog.

## Platform

| | |
|---|---|
| Windows | 10 and 11, x64 |
| Terminals | Windows Terminal, the classic console, VS Code's terminal. For fonts without box-drawing characters, set borders and glyphs to *ascii* |
| Browsers (web view) | Any current Chromium, Firefox or Safari |
| [Windows Sandbox](/docs/using/sandbox) (`S`) | Windows 10/11 Pro, Enterprise or Education with virtualization on; not Home |

## Per-tool caveats

Tools with a known caveat carry a [`note:`](/docs/catalog/verify-and-notes) that's printed on every run. The [catalog table](/docs/catalog/overview) marks them with `note`.
