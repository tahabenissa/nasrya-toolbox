Location: `%APPDATA%\winsploit\settings.yaml`. It's written when you press `Enter` in the [appearance panel](/docs/using/appearance), when you pick an [agent](/docs/using/agent) provider or model, and when the welcome tour finishes. You can edit it by hand; missing keys keep their defaults.

```yaml
theme: frost
borders: rounded
glyphs: unicode
bold: true
overlay: docked
backdrop: dim
agent: claude
agent_models:
  ollama: qwen2.5-coder
```

| Key | Values | Default |
|---|---|---|
| `theme` | `frost`, `dark`, `light`, `dark-daltonized`, `light-daltonized`, `dark-ansi`, `light-ansi`, `cyan` | `frost` |
| `borders` | `rounded`, `plain`, `double`, `thick`, `ascii` | `rounded` |
| `glyphs` | `unicode`, `ascii` | `unicode` |
| `bold` | `true`, `false` | `true` |
| `overlay` | `docked`, `centered` | `docked` |
| `backdrop` | `dim`, `none` | `dim` |
| `agent` | `claude`, `gemini`, `deepseek`, `openai`, `ollama` | `claude` |
| `agent_models` | provider → model name; a missing provider uses its default | empty |
| `redact` | `off`, `commands`, `all`: how much to mask secrets. `commands` masks command lines (the pane's `$` line and the run log) and what you type at a password prompt; tool output stays verbatim, because a cracked credential is a finding. `all` also masks secret patterns in the log's tool output. Text sent to an AI provider is masked unless this is `off`. See the [security model](/docs/security/model#secrets-stay-out-of-the-pane-and-the-logs) | `commands` |
| `chat-autorun` | `true`, `false`: run the [side chat](/docs/using/chat)'s plans without waiting for `Enter`. Off by default, because tool output is untrusted text that reaches the AI | `false` |
| `update-check` | `true`, `false`: show a toast at start-up when a newer release is out | `true` |
| `tour_done` | `true`, `false` | `false`; set when the welcome tour finishes. Set it back to `false` to see the tour again |

`frost` is Winsploit's own look, the same palette as the web view. The `dark-ansi` / `light-ansi` themes use only the terminal's 16 ANSI colors, so they follow your terminal's own palette. `cyan` is *Winsploit classic*.

## The web view's settings

The web view keeps its own settings (colors, light / dark, text size, density, the tool list and panel sizes) in the browser's local storage, not in `settings.yaml`. They're per browser: another browser or a LAN guest starts from the defaults (Frost). Open them with `,` or the gear in the top bar.
