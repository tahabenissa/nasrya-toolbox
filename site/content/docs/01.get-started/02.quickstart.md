## The easy way: setup.exe

Download `winsploit-<version>-setup.exe` from the [Releases](https://github.com/tahabenissa/winsploit/releases) page and run it. No admin rights are needed.

- It installs to `%LOCALAPPDATA%\Programs\Winsploit` and can add that folder to your PATH, so a **new** terminal understands `winsploit`.
- It can install Scoop and git, add the catalog's buckets, and set up Python and pipx. Anything already on your machine is shown as "found, skipping". Scoop cannot be installed from an elevated setup.
- You can tick **tool packs** (one per category, plus a CTF starter). Winsploit never installs on its own: the first time you start it, it lists every tool in your packs and asks before installing.
- Uninstall removes the program, shortcuts and PATH entry. It never touches Scoop, installed tools or your `ctf` folder, and asks before deleting settings and logs.

Silent install: `winsploit-<version>-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /COMPONENTS="main,path,scoop,buckets" /TASKS="wtprofile" /PACKS=recon,web`

The installer is unsigned, so SmartScreen may ask you to choose "More info", then "Run anyway". Compare the file with `SHA256SUMS` on the release. The steps below are for building from source.

## What you need

- **Windows 10 or 11**
- [**Scoop**](https://scoop.sh): Winsploit installs tools through it
- [**Rust 1.87+**](https://rustup.rs) to build from source

## 1. Install Scoop

Skip this if `scoop --version` already works.

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression
```

## 2. Build Winsploit

```powershell
git clone https://github.com/tahabenissa/winsploit
cd winsploit
cargo build --release
```

## 3. Launch the dashboard

```powershell
.\target\release\winsploit setup --path   # once: makes `winsploit` a command
# then, in a new terminal, from the folder you're working in:
winsploit
```

A development build finds the checkout's `tools.yaml` from any directory, so you can run it from wherever you like. Tools run in the folder you start it from; `d` changes it, like `cd`. The first launch asks whether to continue in the terminal or also open the [web view](/docs/web-view/overview), then shows a three-step tour.

## 4. Install and run a tool

1. Move to a tool with `↑` `↓`, switch category with `←` `→`, or press `/` and type to filter.
2. If it shows `○` (missing), press `i`. The install streams into the **console** (terminal 0).
3. Press `Enter`. The arguments prompt opens with an example prefilled; edit it and press `Enter` again.
4. The tool runs in its own terminal. Press `?` any time to see every key.

::callout{type="tip"}
Try `nmap` first: it's in the main Scoop bucket, and its prefilled arguments scan `scanme.nmap.org`, a host the Nmap project provides for exactly this.
::
